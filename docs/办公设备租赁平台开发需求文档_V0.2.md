## 1. 目标与范围

**目标**：建立 C 端高价值办公设备租赁小程序的开发需求基线，覆盖选品、计费、押金/免押、下单签约、交付回收、归还定损与结算闭环。业务逻辑对标哈啰租车（取还 → 选品 → 选期 → 计价 → 免押 → 下单支付 → 交付验机 → 使用 → 归还结算）。

**范围内（一期）**：C 端小程序、设备选品与搜索、档期库存、在线计价、信用免押与押金、电子签约、支付、自提/配送、上门回收、归还验收与定损、运营管理后台、消息通知。

**范围外（一期）**：商家入驻、B 端企业账户/合同/审批、对公与月结、多商家分账；B 端能力进入二期。

## 3. 平台定位与商业模式

- **REQ-BIZ-01** 平台形态：一期**平台自营**（C 端），二期扩展 B 端。
- **REQ-BIZ-02** 用户重心：一期 **C 端个人用户**。（问卷 2 填「B/C 并重」，**被最终决议覆盖**）
- **REQ-BIZ-03** 收入来源（问卷 3）：租金差价、服务费（配送/安装/回收）、增值服务（保险/耗材/维保）、押金与租赁金融、流量/推广。一期以**租金差价 + 服务费 + 保险**为主。
- **REQ-BIZ-04** 以租代购 / 租满即送（问卷 4）：问卷填「支持」；一期【待确认】是否上线，建议后期再做。

## 4. 设备品类与商品

- **REQ-CAT-01** 一期品类（聚焦高价值设备）：投影仪、相机、镜头、无人机、直播设备、会议平板/视频会议设备、笔记本电脑、平板等。**一期具体 SKU 清单【待确认】**。
- **REQ-CAT-02** 资产模型（问卷 6）：**贵重设备一机一码（唯一资产 + SN）**，耗材/配件按数量。
- **REQ-CAT-03** 商品属性（问卷 7）：品牌、型号、成色、配置参数、序列号 SN、采购日期、所在仓库/网点、配件清单、实拍图、说明书/电子资料、日/月租金、押金。
- **REQ-CAT-04** 设备状态与档期（问卷 8）：状态机（可租/在租/维修/报废），**必须按档期锁定库存**。

> **设计约束**：商品分两层 —— 「SKU（规格）」+「资产实例（SN）」。下单按档期占用到资产实例，避免超租。

## 5. 租期与计费

- **REQ-PRICE-01** 计费周期（问卷 9）：按天 / 周 / 月 / 年 / 合同期。
- **REQ-PRICE-02** 计价模式（问卷 10）：固定单价 / 阶梯价（越久越便宜）/ 套餐（如周租包）/ 一客一议。
- **REQ-PRICE-03** 起租门槛（问卷 11）：**无起租，最短 1 天**。
- **REQ-PRICE-04** 续租 / 退租 / 换机（问卷 12）：支持**续租、换机（维修/升级）**；提前退租规则【待确认】。
- **REQ-PRICE-05** 运费 / 安装费（问卷 13）：**单列收取**。

## 6. 库存与交付

- **REQ-STOCK-01** 交付方式（问卷 14）：到店/网点自提、**上门配送 + 安装调试**、**上门回收**。高价值相机/镜头建议增加「保价寄送」——【待确认】。
- **REQ-STOCK-02** 耗材/配件（问卷 15）：一期**后期再做**。
- **REQ-STOCK-03** 备用机（问卷 16）：一期**不提供**。
- **REQ-STOCK-04** 多仓/门店调拨（问卷 17）：**需要**。

## 7. 用户与账户

- **REQ-USER-02** 账户体系（问卷 19）：问卷填「必须区分个人/企业」；**一期仅个人账户**，企业账户归二期。
- **REQ-USER-03** 合同签署（问卷 20）：**电子合同（在线签署）**，C 端个人租赁协议。
- **REQ-USER-04** 会员/信用/黑名单（问卷 21）：会员等级、信用分、黑名单。

## 8. 下单与合同流程

- **REQ-ORDER-01** C 端下单流程（问卷 22）：选设备 → 选租期 → 选交付地址/取还方式 → 信用免押/押金 → 电子签约 → 支付 → 待交付 → 使用中 → 归还 → 结算/押金退还。
- **REQ-ORDER-02** 询价/跟单（问卷 23）：一期 C 端**在线自主下单**（问卷「销售报价」归二期）。
- **REQ-ORDER-03** 电子签名与合同存档（问卷 24）：**需要**。
- **REQ-ORDER-04** 企业审批（问卷 25）：**归二期**。

## 9. 支付、押金与结算

- **REQ-PAY-01** 支付方式（问卷 26）：微信支付、支付宝（对公归二期）。
- **REQ-PAY-02** 押金方式（问卷 27）：**押金授权（预授权/冻结）为主，信用免押兜底**（芝麻信用 / 微信支付分）。押金额度、免押上限与差额补押规则**按设备价格在运营后台逐设备/分类自定义配置，不写死**。高价值相机/镜头一般走押金授权。
- **REQ-PAY-03** 押金退还（问卷 28）：**人工确认后退还**。
- **REQ-PAY-04** 支付节奏（问卷 29）：问卷「按合同」；C 端建议**下单一次付清（租金+押金）**——【待确认】。
- **REQ-PAY-05** 发票（问卷 30）：普票 / 电子发票（C 端个人通常不需要，保留能力）。
- **REQ-PAY-06** 损坏/丢失赔付（问卷 31）：问卷「人工协商」；建议补充**标准赔偿表**用于高价值设备——【待确认】。
