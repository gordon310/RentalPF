## 1. 目标与范围

**目标**：建立办公设备租赁平台的开发需求基线，覆盖平台形态、商品资产模型、租期计费、支付押金、交付归还与风控闭环。业务逻辑对标哈啰租车（取还 → 选品 → 选期 → 计价 → 免押 → 下单支付 → 交付验机 → 使用 → 归还结算）。
